# Spectrum

A modern, material-designed Android application to quickly switch between network modes (5G, 4G LTE, 3G, etc.). This app provides a convenient way to access hidden network settings and includes a Quick Settings Tile for even faster switching.

## ✨ Features

- **One-Tap Access:** Quickly open the system's preferred network type settings.
- **Support for All Modes:** Easily switch between 5G, 4G (LTE), 3G, and 2G.
- **Quick Settings Tile:** Toggle or access settings directly from your notification shade.
- **Modern UI:** Built with Jetpack Compose and Material 3 design principles.
- **Glassmorphic Elements:** Features a sleek, modern aesthetic with glass-style cards.
- **Network Monitoring:** Background service to keep track of your network state.

## 🛠️ Built With

- **Kotlin** - Primary programming language.
- **Jetpack Compose** - For the modern, declarative UI.
- **Material 3** - Design system components.
- **Dagger Hilt** - Dependency injection.
- **Android Architecture Components** - ViewModel, Flow, etc.

## 🚀 Getting Started

1. Clone the repository.
2. Open in Android Studio (Ladybug or newer).
3. Build and run the app on your device.

## ⚠️ Important Note

Forcing a specific network mode (like "5G Only") may result in no signal if your current area does not have coverage for that specific frequency. Use with caution.
